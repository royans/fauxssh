About FauxSSH

Learn more about the technology behind this honeypot network.

High-Interaction Decoy

FauxSSH is a next-generation "hallucinating" honeypot. Unlike traditional low-interaction sensors that return static banners or simple shells, FauxSSH emulates a fully functional Linux environment across multiple protocols.

By leveraging Large Language Models (LLMs), it generates BELIEVABLE responses to any command an attacker types. If an attacker tries to cat a file, the LLM hallucinates realistic content. If they try to download a payload, FauxSSH simulates the network interaction while capturing the threat data.
